# Bithra 🌱 | Smart Home Gardening Store

**Bithra** (Arabic for "Seed") is a specialized Django-based e-commerce platform designed to promote sustainability and food security by making home gardening accessible to everyone. The project provides a curated collection of organic seeds with smart, time-based planting recommendations.

---

## ✨ Key Features

### 1. **Dynamic Planting Calendar (The Logic Core)**
The highlight of the project. It uses real-time Python logic (`datetime` library) to filter and suggest the best seeds to plant based on the current month. It also features a **Yearly Roadmap** timeline for year-round planning, ensuring users know what to prepare for in upcoming seasons.

### 2. **Interactive Seed Store**
A visually rich catalog displaying seeds fetched directly from the database. The store is organized into intuitive categories:
* **Herbs**
* **Vegetables**
* **Leafy Greens**

### 3. **Digital Care Cards**
Every seed has a dedicated detail page ("Care Card") designed to act as a digital guide for the grower. It displays essential metadata:
* **Sun Exposure:** Optimal light conditions.
* **Watering Needs:** Precise irrigation frequency.
* **Best Season:** The specific month recommended for planting.
